# Organics Theme Documentation Summary

This document provides a summary of the [Organics Theme Documentation](https://organics.axiomthemes.com/doc/).

## Custom Post Types (CPT)

The theme utilizes the **ThemeREX Utilities** plugin to manage several custom post types:

- **Services**: For displaying service offerings. Managed via `Admin -> Services`.
- **Team**: For staff profiles and team members. Managed via `Admin -> Team`.
- **Testimonials**: For customer reviews and feedback. Managed via `Admin -> Testimonials`.
- **Clients**: For displaying client logos or partners. Managed via `Admin -> Clients`.

*Note: Portfolios are often implemented using standard posts with specific categories or via dedicated page templates in this theme structure.*

## Taxonomies

- **Categories**: Standard WordPress categories.
- **Post Formats**: Standard formats including Gallery, Video, Audio, Link, Quote, Image, Status, Aside, and Chat.
- **Service Categories**: Grouping for Service posts.
- **Team Categories**: Grouping for Team posts.
- **Client Categories**: Grouping for Client posts.
- **Review Criteria**: Metrics used for the built-in rating system.

## Page Templates & Layouts

### Page Templates
- **Blog Streampage**: Dedicated layout for blog feeds.
- **Single Portfolio Item**: Specialized layout for individual portfolio entries.
- **Single Standard**: Default layout for standard posts.
- **Page 404**: Custom error page layout.

### Layout Styles
- **Classic**: Available in 2, 3, or 4 columns.
- **Masonry**: Available in 2, 3, or 4 columns.
- **Portfolio**: Available in 2, 3, or 4 columns.
- **Grid Tile**: Grid-based display.
- **Square Tile**: Square grid display.

## Widget Areas

- **Main Sidebar**: Primary vertical sidebar (positionable Left or Right).
- **Footer Sidebar**: Widget area located in the site footer.
- **WooCommerce Cart Sidebar**: Dedicated area for the shopping cart widget.
- **Custom Sidebars**: Unlimited custom sidebars can be created via `Theme Options > Customization > Sidebars`.

## Recommended Plugins

### Required
- **ThemeREX Utilities**: Essential for core theme functionality and CPTs.

### Recommended
- **Elementor** or **WPBakery PageBuilder**: For page construction.
- **WooCommerce**: For e-commerce functionality.
- **Revolution Slider**: For advanced sliders.
- **Essential Grid**: For grid layouts.
- **Contact Form 7**: For forms.
- **MailChimp for WP**: For newsletter integration.
- **Product Delivery Date for WooCommerce**: Specific e-commerce utility.
- **ThemeREX Updater**: For theme updates.

## Theme Options

Located under `Theme Options > Global Options`:

- **Customization**: Body styles (Boxed/Wide), Header/Logo settings, Slider configuration, Sidebars, Footer.
- **Blog and Single**: Stream page layouts, post meta (author, date, tags), pagination, related posts.
- **Reviews**: Configuration of total rating systems (Stars, 10-point, 100%).
- **Media**: Image dimensions, Retina settings, media player defaults.
- **Socials**: Social profile links, share buttons, API keys (e.g., Twitter).
- **Contact Info**: Settings for physical address, phone, email in headers/footers.
- **Search**: AJAX search settings.
- **WooCommerce**: Shop layout styles, currency settings, cart visibility.
- **Service**: Advanced settings (AJAX counters, debug mode, frontend editor).
